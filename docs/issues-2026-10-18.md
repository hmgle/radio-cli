## #2

## 行为与兼容性选择

- Ctrl-C 始终收尾退出，Esc 取消输入或关闭弹窗；q 在普通模式退出，帮助中关闭帮助，筛选/输入中可作为文本。终端过小时 q 直接退出。
- TUI 录音属于当前播放会话，暂停继续录音，换台/失败/停止/退出会收尾；独立录制使用 CLI `radio record UUID`。
- `favorites list`、`history`、`recordings list` 的 JSON 现在是 `{items,total,limit,offset,has_more}`；`--all` 的 limit 为 null。`search --json` 保留数组兼容性。录音列表新增 `recordings recover` 重试入口。
- 数据库自动迁移到 schema v2，用显式 `recovery_pending` 保存录音恢复资格，旧待恢复记录迁移保留；新录音 JSON 和 sidecar 包含该布尔字段。
- 目录缩减超过 25% 默认保留旧目录并立即返回，可在核实后用 `sync --accept-shrink` 明确接受；网络失败仍允许换服重取。`last_sync_attempt` 保存各次尝试的服务器、诊断及原始、有效、无效、重复和唯一计数。
- 文件发布协议针对进程崩溃恢复，不承诺突然断电时文件系统与 SQLite 的跨介质原子持久性。上游目录没有快照隔离，固定服务器避免副本拼接，但不能消除同一服务器分页期间的数据变化。
- 慢外部 I/O 场景测试的控制响应预算为 250 ms；文件验证上限 2 秒，FFmpeg 优雅停止上限 3 秒，TUI 退出最多等待后台收尾 6 秒。该预算不构成任意磁盘或 SQLite 锁竞争下的实时保证。
