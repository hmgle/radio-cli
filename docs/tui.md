# TUI 操作与设计

运行 `radio tui`，按 `:` 输入内置命令，Enter 执行，Esc 回到普通模式。比如首次打开后输入 `:sync`，即可在界面内同步完整目录；期间仍能切换面板、搜索、暂停和调音量。任务面板显示进度、完成状态和错误，`:sync-cancel` 请求取消；取消时保留原目录；正在进行的 HTTP 请求在后台结束或超时，其结果被忽略，不阻塞媒体控制和退出。

`F` 打开筛选弹窗，按当前字段和输入前缀从本地目录后台查询候选和电台数；↑/↓ 选择并填入，
Tab 切换字段，Enter 应用，Ctrl-U 清空全部筛选，Esc 取消；点击底栏明确的“清空筛选 / Clear”标签也可清空搜索与筛选；点击摘要、模式徽标或空白不会清空。也可直接输入。`:search --sort bitrate --min-bitrate 128`
按码率排序；可选排序为 `name|bitrate|votes|clickcount|random`，默认 `clickcount`。

## 面板与焦点

| 编号 | 面板 | 操作 |
|---|---|---|
| `1` | 来源 | `j/k` 选择电台、收藏、最近、录音；Enter 进入列表 |
| `2` | 列表 | `j/k` 选择、Enter 播放、`f` 收藏；`gg/G` 首尾，Ctrl-u/d 移动十项 |
| `3` | 详情 | `j/k` 或 PgUp/PgDn 滚动电台与录音信息 |
| `4` | 播放器 | Enter 打开当前电台完整详情 |
| `5` | 任务与消息 | `j/k` 滚动历史消息，默认跟随最新消息 |

Tab / Shift-Tab 循环切换面板；Ctrl-h/j/k/l 或 Ctrl-方向键按位置切换。左右方向键与 `h/l` 也移动焦点。`[` / `]` 在任意面板切换来源分类。鼠标点击聚焦面板、选中列表项，列表滚轮每次移动三项；详情和任务区滚轮滚动内容。帮助滚轮滚动弹层，筛选滚轮选择候选，不作用于背景；来源和播放器区域的滚轮不改变焦点。

电台或录音列表中，在同一行的同一位置 500 ms 内双击可播放；单击（包括左右边框）仍只选行。
双击播放限于边框内的有效行；移动、拖动、滚动、键盘输入、弹窗、禁用鼠标、
布局变化或列表数据修订都会取消双击手势。

活动面板用亮青色粗边框、`▶` 标记和高亮标题表示，列表选中项另有反色与箭头；底栏同时显示 `NORMAL` 和面板名。终端禁用颜色时仍可通过粗边框与箭头识别。切换输入模式时，底栏显示 `COMMAND` 或 `SEARCH`，普通模式的播放、录音、退出按键不再响应文本输入。

100 列且至少 20 行时显示三列主区；窄终端的列表与详情共享区域，默认显示列表，用 `2` / `3` 切换。最小尺寸为 40×16；低于 20 行时后台任务仅占一行摘要，按 `5` 用主区查看任务，按 `2` 返回列表。
更小时只接受 `q` / Ctrl-C 退出和 Esc 取消；删除确认取消、编辑草稿保留，未发出的界面查询等恢复尺寸后再发送。
已有播放、录音和同步继续运行。

列表查询失败显示原因摘要，`F5` 保留当前筛选重试，Enter 查看完整原因；失败和加载期间旧行不可操作。
末页因删除或目录收缩越界时自动回到最后有效页；没有匹配项、没有收藏、没有历史及没有录音分别给出提示。

删除弹窗显示对象名称（已知时）、ID 和删除范围。`y` 确认，`Enter/n/Esc/q` 取消，Ctrl-C 退出；
其余快捷键在确认期间不执行。队列满时保留确认供重试；“已提交”不代表删除成功。
运行错误在底栏持续提示，`?` 查看完整原因，普通模式 Esc 关闭提示；诊断内容也保留在任务日志。

## 命令

| 命令 | 含义 |
|---|---|
| `:sync` / `:sync-cancel` | 后台同步 / 请求取消目录任务 |
| `:search jazz --country FR --min-bitrate 128` | 按 CLI 参数搜索当前电台分类 |
| `:play [UUID或URL]` | 播放列表选中项、指定电台或临时 HTTP(S) 流 |
| `:random [搜索参数]` | 随机电台；无参数时沿用当前筛选 |
| `:info [UUID]` | 在详情面板查看选中或指定电台 |
| `:current` | 查看当前播放电台完整详情 |
| `:favorites list` | 切换到收藏列表 |
| `:favorites add [UUID]` / `:favorites remove [UUID]` | 收藏 / 取消收藏，省略 UUID 时使用选中项 |
| `:history` / `:recordings list` | 最近播放 / 录音列表 |
| `:station add '我的电台' https://example.com/live --backup-url https://example.com/backup` | 添加自定义电台和备用地址 |
| `:station list` / `:station edit UUID --name 名称 --url URL` | 列出或修改自定义电台；`--backup-url` 可替换备用地址 |
| `:station remove UUID [--keep-references]` | 按 `y` 二次确认，Enter/`n`/Esc/`q` 取消；被引用时保留名称占位并清除播放地址 |
| `:station backups UUID [--add URL] [--remove URL]` | 查看或修改备用地址，详情面板也展示备用地址 |
| `:record [UUID] --duration 30m --output-dir './my music'` | 录音；省略 UUID 时录制当前实际播放线路 |
| `:record stop` | 收尾录音文件 |
| `:pause` / `:stop` / `:volume 70` | 暂停或恢复 / 停止播放并收尾录音 / 音量 |
| `:doctor` | 在任务面板展示依赖检查结果 |
| `:focus sources\|list\|details\|player\|activity` | 聚焦指定面板，也接受 `1`–`5` |
| `:help` / `:quit` / `:q` | 帮助 / 收尾并退出 |

命令只调用程序内置操作，不执行 shell。支持单引号、双引号和转义，路径相对启动目录解释。Tab / Shift-Tab 按上下文循环补全命令、参数或 UUID，↑/↓ 浏览持久命令历史，←/→、Home/End 编辑，Ctrl-a/e 到行首/尾，Ctrl-u 清空，Ctrl-w 删除前一个词。参数错误保留输入并展示原因；运行错误写入任务面板。进程级 `--config`、`--data-dir`、`--api-url`、`--json` 不可在已运行的 TUI 内修改。

`:play https://example.com/live` 使用临时电台，不写入目录、历史或上次电台偏好；
`:current` 可查看完整流地址，展示名称最多 60 字符。临时流不支持录音，需先用
`:station add` 保存。`radio devices` 在独立 CLI 中列出音频设备，配置 `audio_device`
选择输出；`normalize_loudness = true` 仅影响播放，录音仍原流复制。

配置 `resume = false` 默认打开全部电台且不播放；`true` 恢复来源并自动播放上次电台；
`"selection"` 恢复来源和上次电台所在分页，只选择、不播放。恢复选择仅在首批匹配行到达时
尝试一次；目标不可用时回退首行，录音来源仅恢复来源。

`/` 进入增量搜索，200 ms 消抖；Enter 确认，Esc 恢复进入前的查询。两个字符及以上的查询还会按子串匹配国家/地区的中文名称（单字符查询只匹配电台文本）。`F` 编辑国家/地区代码、语言、标签和最低码率，代码候选附带中文名称。搜索期间方向键编辑输入，普通模式的 PgUp/PgDn 才切换数据库分页。`?` 打开可滚动帮助。

## 当前播放信息

顶部始终展示当前播放电台名称、编码、码率、音量、暂停与录音计时；高度足够时再显示国家/地区代码、语言和实时曲名。列表移动不改变此处的播放对象。

按 `4` 再 Enter，或执行 `:current`，打开该电台的国家/地区、语言、州/省/区域、码率、编码、HLS、标签、收藏状态、目录状态、UUID、流地址、实际播放请求地址与官网。国家/地区名称按代码使用 CLDR 中文名称，代码无法识别或缺失时回退显示上游目录名称，再回退代码，最后显示未知；原始目录名称保留在 JSON 中。录音列表的详情展示编码、容器、时长、文件大小、路径和失败原因。详情在列表移动或分类切换后恢复跟随选中项。

默认目录来自 Radio Browser，来源说明见 README；帮助面板中的该说明随界面语言切换。

普通模式下连按 `''`（两次单引号，间隔不超过 1 秒）定位当前播放电台并聚焦列表。
目标在当前页时保留来源、筛选和排序；否则切到“全部电台”，清除筛选并使用默认排序，
只加载目标所在页。定位不重新播放。暂停、连接和重连期间同样可定位；无播放时提示。
本地录音播放时定位对应电台；电台已不在本地可浏览目录时提示使用 `:current` 查看详情。

可在配置文件中自定义：

```toml
[keybindings]
jump_to_playing = "''" # 也可用 "gp"、"<F6>"、"<Ctrl-p>"
```

支持 1–4 个可打印非空白字符，或一个 `<F1>`–`<F12>`、`<Space>`、`<Home>`、
`<End>`、`<Enter>`、`<Tab>`、`<Left>`、`<Right>`、`<Up>`、`<Down>` 等命名键；
命名键可带 `Ctrl-`、`Alt-`、`Shift-` 修饰。自定义绑定优先于原普通模式按键，
因此应避免覆盖常用操作；Ctrl-C 保留退出用途。设为 `""` 可禁用定位快捷键。
以 `<` 开头的配置必须是完整命名键。Ctrl 字符键不区分大小写，额外 Shift 不改变匹配。
帮助显示实际配置的按键，禁用时不显示定位条目。
搜索、命令、筛选弹窗和帮助内不会触发定位。`''` 借用 Vim 跳转手感，
[Vim 的原义](https://github.com/vim/vim/blob/master/runtime/doc/motion.txt)是返回上次跳转前的位置；
本程序将其定义为定位当前播放项。

码率与编码来自 Radio Browser 目录，标注“目录”，可能与当前音源不同；自定义电台通常显示未知。这里尚未做实时流码率测量。实际录音编码仍通过 ffprobe 探测；播放曲名来自播放器收到的元数据。请求地址可反映备用线路，HTTP 重定向后的最终 CDN 地址未必可见。

## 设计参考与边界

面板编号、Tab 焦点、分类切换和上下文提示参考 [lazygit 的按键设计](https://github.com/jesseduffield/lazygit/blob/master/docs/keybindings/Keybindings_en.md)；视图导航、搜索与命令入口参考 [tig 手册](https://jonas.github.io/tig/doc/manual.html)，输入模式采用 Vim 风格。保留收音机所需的五个面板与快捷操作，避免引入完整 Vim 编辑器或 shell。

目录任务独立运行，重复同步会提示已有任务，失败与取消保留原目录。媒体命令由所有者线程串行协调；播放启动、线路刷新、录音探测和收尾在后台执行，暂停、停止和音量通过优先队列处理。没有后台守护进程；退出后停止媒体并等待任务收尾。

流连接或断流失败可回退候选线路；播放器本地启动失败（含 IPC/socket 超时、缺依赖、
缺滤镜）或配置的设备失败会直接结束本次播放，不换线路、随机电台或刷新目录。
修复本地问题后重新播放；偶发启动失败也需重新发起播放。
录音请求会冻结当时的曲名，写入文件名和元数据；后续切歌不会改名，未知曲名沿用旧格式。

Ctrl-C 在所有 TUI 模式下收尾并退出；Esc 取消编辑或关闭弹窗。终端过小时，q 直接退出。

收藏、历史和录音列表均支持 PgUp/PgDn 分页，列表标题显示当前条数及总数。
命令行 `favorites list`、`history`、`recordings list` 支持 `--limit`、`--offset` 和 `--all`。
这些列表的 `--json` 输出为 `{items,total,limit,offset,has_more}`；`--all` 导出全部剩余条目，
此时 `limit` 为 null。`search --json` 为兼容现有脚本仍返回数组。录音按开始时间和 ID
稳定排序，更新录音状态不会将旧任务排到首位。TUI 使用分页，`--all` 仅供命令行导出。

F5 或 `:refresh` 刷新当前列表。媒体工作线程同时检测本连接写入与 SQLite
`data_version` 变化，播放成功后的历史、其他 CLI 会话的收藏编辑会自动反映到列表。
详情查询按请求编号展示加载、成功或错误状态，查询失败不会保留上一台的详情。

TUI 录音附属于当前播放会话：`:record UUID` 仅接受正在播放的同一电台，其他 UUID
明确报错；`r` / `:record` 录制当前实际线路（包括备份）。暂停不停止录音，换台、
播放失败、`:stop` 或退出会收尾录音；`:record stop` 仅结束录音。独立录制其他电台
请使用 CLI `radio record UUID`。播放器的 REC 标记对应当前播放电台。

本地录音列表中，Enter 播放选中的文件，`o`（或 `:open recordings`）
用 `xdg-open` 打开录音目录，`e` 在详情面板展开完整 FFmpeg 错误尾部。
`D` 删除选中录音，按 `y` 确认，Enter/`n`/Esc/`q` 取消。
默认先删除音频和 sidecar，成功后删除索引；文件操作失败时保留索引，
重试允许文件已不存在。`:recordings remove ID --index-only` 仅删除索引、
保留文件，同样需要确认。录制、收尾和仍待恢复的记录不能删除。
本地播放不产生电台收听历史，不发送目录点击统计，播放结束后自动停止。

CLI 对应命令为 `radio recordings play ID`、`radio recordings remove ID
[--index-only]`、`radio recordings open`。CLI 删除命令直接执行。
录音前检查可用空间：`recording_min_free_mb` 默认保留 16 MiB，再加上
已知码率乘以指定时长的估算空间。不足时拒绝开始，不创建临时录音。
`radio doctor --json` 的 `recording_space` 检查返回可用和最低空间字节数。

80×24 的播放器压缩为两行内容；空闲任务面板收起为一行，目录任务运行或聚焦
`5` 时展开。窄于 100 列时详情默认收起，`3` 打开共享主区域的详情，`2` 返回列表，
标题的 `[2/3]` 标记提示切换入口。100 列及以上、至少 20 行时使用三列主区。
自动快照覆盖 80×24、100×24、160×48 的列表和详情状态。

配置项 `theme = "default" | "mono" | "light"` 选择配色。
默认主题沿用终端背景；mono 去除颜色及全部 SGR 属性，通过文字、边框和箭头识别；light 使用白底深色文字、
蓝色焦点和白字蓝底选中项。非空 `NO_COLOR` 环境变量强制 mono，优先于配置。
三种主题在 80×24 下保持相同内容与焦点标记；自动检查浅色主题文字前景不等于背景；这不等同于真实终端对比度验证。

`probe_timeout_secs` 独立控制录音前的 ffprobe 探测，默认 5 秒（1–300）；
`playback_timeout_secs` 继续只控制播放起播期限，录音收尾验证仍有自己的短超时。
播放控制器拥有播放器、候选线路、重连与代次；录音控制器拥有探测、录制和收尾任务，
Engine 负责协调共享服务及退出。CLI 和 TUI 共用电台服务与数据库写入策略。

播放器状态明确区分待机、连接中、重连中、播放中、暂停和失败；录音独立显示
检测编码、正在录音、收尾、已保存或失败，调音量等消息不会覆盖录音阶段。
失败时按 `?` 查看完整原因，`:help` 始终打开操作帮助。列表优先保留名称、选择、收藏及失效信息，剩余宽度足够时才显示国家/地区代码、码率和编码；长名称按显示单元截断并加省略号。
退出时持续显示“正在退出 / 正在收尾录音”，完成有界媒体清理后再恢复终端。

视图采用缓存的 `Arc<View>` 快照，各列表、录音、日志共享独立数据与修订号；
录音来源只查询录音，电台来源不读取录音列表。状态变化直接比较字段，
录音计时只按整秒发布；用户输入和状态转换即时重绘，普通进度最多每秒刷新一次。
历史保留最近 1000 条，使用主键阈值清理，避免每次插入排序扫描全部历史。

筛选弹窗的当前字段复用命令编辑器：←/→、Home/End、Ctrl-a/e、Ctrl-w、Delete
均按 Unicode 边界工作；↑/↓ 仍选择候选，Tab 切字段，Ctrl-U 清空全部筛选。
命令 Tab 补全按命令提供参数：`record ` 提供当前/选中 UUID、`--duration` 和
`--output-dir`，时长值提供 10m/30m/1h；`station add ` 提供名称/URL 模板，
添加或编辑参数提供 `--backup-url`，不会混入搜索专用参数。

`m` / `:mute` 切换 mpv 静音；`:help record`、`:help station add` 打开对应命令用法。
`:set language en|zh-CN` 立即切换领域错误与已迁移消息的语言。CLI 顶层帮助简介
已支持语言切换；子命令帮助、静态 TUI 文案和部分运行消息仍待迁移。
此设置只影响当前会话，不改写用户配置文件。

`mouse = false` 或 `:set mouse false` 关闭鼠标捕获，允许终端本身选择文本；
`:set mouse true` 恢复。`y` 发送选中 UUID（录音为 ID）到终端剪贴板，
`Y` 发送 URL（录音为文件路径）。复制使用终端的 OSC 52 支持，最多 4096 字节。
命令历史保存在数据目录的 `command-history.json`，保留最近 100 条、文件权限 0600；
↑/↓ 跨会话浏览，退出历史后恢复原草稿。普通搜索输入不写入命令历史。

`F` 筛选弹窗按键入内容进行不区分大小写的前缀查询，200 ms 消抖，仅查询当前字段，每次最多返回 100 项；继续输入可缩小范围，↑/↓ 在匹配项中选择，Tab 切换字段，Enter 应用；窗口最多显示八项，Ctrl-U 清空筛选。

窄布局中 Ctrl-l 打开详情，Ctrl-h 返回列表。录音来源不显示电台筛选摘要；执行 `n` / `:random` 会切回电台来源。静音状态由 mpv 属性反馈，在播放器头部显示。

备用地址按选中项按需查询，失败会在详情显示原因，依次等待 2、4、8、16 秒重试，
之后每 30 秒重试；相同错误不重复记日志或触发重绘。成功后缓存，列表刷新时失效。
筛选候选连续输入合并为最新请求，同一时间最多执行一次候选查询。
发生过重连的录音在详情和 CLI 列表显示音频可能有缺口，重连次数保存在数据库与 sidecar。
